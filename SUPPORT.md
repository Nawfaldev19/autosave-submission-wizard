# Support

Submission Wizard is a demo project, supported on a best-effort basis by one maintainer.

- **Questions and ideas:** open an issue with the feature request form, or a discussion if they are enabled on the repository.
- **Bugs:** use the bug report form; include steps from a fresh `npm run db:setup`.
- **Security problems:** never in public; follow [SECURITY.md](SECURITY.md).

Before asking, the [documentation map](docs/README.md) and the [getting-started tutorial](docs/tutorials/getting-started.md) answer most setup questions.

What is supported: the latest version on `main`, on Node 22.12+ or 24+ and PostgreSQL 16, run locally or with Docker Compose. Production deployments are not supported.

# Glossary

Terms as they are used in the code, the API and the interface.

| Term                               | Meaning                                                                                                                                                                              | In code                                             |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------- |
| **Press**                          | The publisher running the app (the fictional Larkspur Press). Its authors submit work and its editors decide it from the queue; its time zone decides "today".                       | `config.pressName`, `PRESS_TIME_ZONE`, `Press` type |
| **Viewer**                         | The signed-in user a request acts for.                                                                                                                                               | `Viewer`, `requireViewer`, `requireRole`            |
| **Draft**                          | A submission in status `DRAFT`: editable by its author, invisible to editors. Each one is edited in the five-step wizard, which saves when the author presses **Save and continue**. | `SubmissionStatus.DRAFT`, `web/src/wizard/`         |
| **Step**                           | One page of the wizard: basics, manuscript, schedule, about, review.                                                                                                                 | `STEPS`, `Step` enum                                |
| **Readiness**                      | The list of everything still missing before a draft can be submitted.                                                                                                                | `readiness()`, `ReadinessIssue`                     |
| **Fix link**                       | A link on the review step that opens the step holding a missing field and focuses it.                                                                                                | `?focus=`                                           |
| **Form** (of a work)               | The kind of work: chapbook, essay or collection.                                                                                                                                     | `FORMS`, `Form` enum                                |
| **List** / **season**              | The publishing list asked for: spring, autumn or either.                                                                                                                             | `SEASONS`, `Season` enum                            |
| **Manuscript**                     | The uploaded file of the work (PDF or UTF-8 text, up to 5 MB).                                                                                                                       | `manuscripts` table                                 |
| **Storage key**                    | The random UUID a manuscript's bytes are stored under. Never derived from the file name.                                                                                             | `FileStorage`                                       |
| **Sniffing**                       | Deciding a file's type from its content rather than its name or claimed type.                                                                                                        | `sniffMediaType`                                    |
| **Version**                        | A counter on each submission, bumped by every write; sent back with saves.                                                                                                           | `submissions.version`                               |
| **Conflict**                       | A save against an older version than the stored one.                                                                                                                                 | `ConflictError`                                     |
| **Workflow**                       | The allowed status changes.                                                                                                                                                          | `TRANSITIONS`, `transition()`                       |
| **Transition** / **action**        | One move: submit, withdraw, claim, accept, decline, revise.                                                                                                                          | `WorkflowAction`                                    |
| **Claim**                          | An editor taking a waiting submission into review; only that editor may then decide.                                                                                                 | `claimSubmission`                                   |
| **Decision**                       | Accepting (with a release date) or declining (with a note).                                                                                                                          | `acceptSubmission`, `declineSubmission`             |
| **Release date**                   | The planned publication date: a calendar date in the press's zone, 30 days to two years out.                                                                                         | `release_date`, `releaseDateProblem`                |
| **Locked fields**                  | Fields an accepted submission no longer lets its author change.                                                                                                                      | `LOCKED_AFTER_ACCEPTANCE`                           |
| **Notification** / **message**     | An in-app message to an author about a decision.                                                                                                                                     | `notifications` table                               |
| **Keyset pagination** / **cursor** | Paging by "records before this `(submitted_at, id)`" instead of by offset.                                                                                                           | `encodeCursor`, `PageInfo`                          |
| **Result union**                   | A GraphQL union of a success type and the expected error types a field can return.                                                                                                   | Pothos errors plugin                                |
| **CSRF header**                    | `x-submission-wizard-csrf`, which every GraphQL POST must carry.                                                                                                                     | `CSRF_HEADER`                                       |
| **Revocation**                     | Ending sessions server-side by moving `sessions_valid_after` forward.                                                                                                                | `signOut` in `domain/auth.ts`                       |

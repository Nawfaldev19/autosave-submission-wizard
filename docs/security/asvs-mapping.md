# OWASP ASVS 5.0.0 mapping

A chapter-level self-assessment against the [OWASP Application Security Verification Standard 5.0.0](https://owasp.org/www-project-application-security-verification-standard/). It records which controls the repository implements, where, how they are tested and what is missing. It is not an audit, and individual requirement IDs are not cited. Test names are in the [threat model](threat-model.md).

| Chapter                                     | Controls (where)                                                                                                                                                                                                                                                                                          | Verification                                                                               | Gaps                                                                                          |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| **V1 Encoding and Sanitization**            | React escapes rendered text; messages are plain text; Drizzle parameterises SQL; download names encoded for `Content-Disposition`, with RFC 8187 `filename*` ([`app.ts`](../../server/src/http/app.ts))                                                                                                   | API tests on real SQL; the `filename*` test                                                | —                                                                                             |
| **V2 Validation and Business Logic**        | Shared Zod schemas on both sides, strict patches, closed GraphQL inputs; the workflow table under a record lock; check constraints; versioned writes ([`shared/src`](../../shared/src))                                                                                                                   | Rules tests; invariant, simultaneous-claim and malformed-id API tests                      | No per-author quotas.                                                                         |
| **V3 Web Frontend Security**                | A `'self'`-only CSP on the built app, framing and sniffing headers, an HTTP-only `SameSite=Lax` cookie, no tokens in web storage ([`vite.config.ts`](../../web/vite.config.ts))                                                                                                                           | `e2e/headers.spec.ts`                                                                      | The dev server sends no CSP.                                                                  |
| **V4 API and Web Service**                  | POST-only GraphQL, a CSRF header, a CORS allow-list, foreign origins refused, a body limit, clamped page sizes, introspection off in production, headers on every response                                                                                                                                | Transport tests in `api.test.ts`                                                           | No query depth or cost limit.                                                                 |
| **V5 File Handling**                        | 5 MB cap before buffering; the whole file checked for PDF or UTF-8; random keys with exclusive create; names as data; authorised `attachment` downloads with `nosniff`, a sandboxing CSP and `no-store` ([`uploads.ts`](../../shared/src/uploads.ts), [`storage.ts`](../../server/src/domain/storage.ts)) | Upload and download tests; e2e disguised binary                                            | No malware checking; a crash after a commit can leave a stray file.                           |
| **V6 Authentication**                       | scrypt with salts and constant-time comparison; a decoy hash; one message for every failure; budgets per client, per client and email, and per email ([`domain/auth.ts`](../../server/src/domain/auth.ts))                                                                                                | `auth.test.ts`; the four rate-limit API tests                                              | Seeded accounts with a published password; no MFA, password reset or breached-password check. |
| **V7 Session Management**                   | A signed 12-hour token in an HTTP-only, `SameSite=Lax` cookie, `Secure` by default in production; server-side revocation on sign-out; the client cache replaced on every change of session                                                                                                                | Cookie and revocation tests                                                                | No renewal, no idle timeout, no per-device revocation.                                        |
| **V8 Authorization**                        | `requireViewer` and `requireRole` first in every service; one visibility predicate (`visibleTo`); writes match `author_id`; only the claiming editor decides; email addresses shown only where needed ([`viewer.ts`](../../server/src/domain/viewer.ts))                                                  | Isolation, role and email-visibility tests; e2e "roles stay in their lanes"                | —                                                                                             |
| **V9 Self-contained Tokens**                | HMAC-SHA256 over the payload, verified in constant time, expiry checked, no algorithm negotiation, revocation by `sessions_valid_after`                                                                                                                                                                   | Token tests in `auth.test.ts`                                                              | The payload (a user id and expiry) is signed, not encrypted.                                  |
| **V10 OAuth and OIDC**                      | N/A — accounts sign in with a password.                                                                                                                                                                                                                                                                   |                                                                                            |                                                                                               |
| **V11 Cryptography**                        | Node's `crypto` only: scrypt, HMAC-SHA256, `timingSafeEqual`, `randomBytes`, `randomUUID`; a secret of at least 32 bytes in production                                                                                                                                                                    | `auth.test.ts`, `config.test.ts`                                                           | Rotating `SESSION_SECRET` ends every session.                                                 |
| **V12 Secure Communication**                | `Secure` cookies by default in production; TLS is expected from a proxy in front                                                                                                                                                                                                                          | Cookie test                                                                                | No TLS or HSTS in the repository.                                                             |
| **V13 Configuration**                       | Every variable parsed with Zod at start-up; bad values stop the process; example secrets refused in production; no secrets committed; GraphiQL off ([`config.ts`](../../server/src/config.ts))                                                                                                            | `config.test.ts`; `npm audit --omit=dev` blocking in CI                                    | Docker Compose uses a placeholder secret, named for local use, without `NODE_ENV=production`. |
| **V14 Data Protection**                     | `private, no-store` downloads; fictional demo data; logs with ids and counts, never passwords, tokens or file contents; email addresses not exposed across roles                                                                                                                                          | Session-cache and email-visibility tests                                                   | No encryption at rest beyond the database host's.                                             |
| **V15 Secure Coding and Architecture**      | Strict TypeScript, one validation boundary, typed errors, `npm ci` from a lockfile, reviewed licences, dependency review, Scorecard and Dependabot ([supply chain](supply-chain.md))                                                                                                                      | `npm run verify`; `.github/workflows`                                                      | CodeQL runs only once enabled in the repository settings.                                     |
| **V16 Security Logging and Error Handling** | Structured JSON logs; unexpected errors masked to clients and logged; expected errors returned as typed values ([`logger.ts`](../../server/src/logger.ts))                                                                                                                                                | "masks unexpected errors: the client gets a generic message and the detail is only logged" | Failed sign-ins and refused moves are not logged as security records; no log shipping.        |
| **V17 WebRTC**                              | N/A — no WebRTC.                                                                                                                                                                                                                                                                                          |                                                                                            |                                                                                               |
